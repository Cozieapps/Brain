# Data and permissions

Beside's personal edition stores content only in its local SQLite database or your Cloudflare SQLite Durable Object. It has no analytics. The UI loads no external fonts, scripts, image assets or trackers. No-AI never calls a model, embeddings API or transcription service.

Saved records cover responsibilities, capture, task checkpoints, memories, people, handoffs, decisions, drafts, pauses, appointments and transitions. Task events, reminders, job attempts, notifications, preferences and attachments are separately persisted. Provider registrations and tokens are held in a different protected runtime vault, never exported with content. Credentials are not placed in frontend storage, source control or transcripts.

User statements, suggestions and inferences retain provenance, review state, timestamps, optional confidence and expiry. They are not silently promoted to facts. Relevant memory retrieval is bounded and profile-scoped. User-driven edits are optimistic-versioned and evented; undo restores the previous reversible state. Forget and full deletion are explicit, permanent actions.

Forgetting an item removes its FTS index rows, event snapshots, jobs, job attempts and notifications. It also clears the profile's conversation history so prior assistant quotations are not reused. Pending model responses are invalidated if content is forgotten while a request runs. Generated artifacts you intentionally saved separately (for example, a draft copied from a memory) remain independent records; review/delete those too. Exports and backups already downloaded to another device cannot be recalled.

The app creates no automatic local backups. Deleted SQLite rows may remain in storage pages, filesystem snapshots or provider recovery history until those systems reclaim them. Cloudflare Durable Objects may retain recovery history under its Time Travel/backup policy; application deletion does not override platform retention. For sensitive permanent erasure, remove the applicable namespace/Worker and request the appropriate retention/deletion procedure from Cloudflare. Do not represent an app-level delete as an instantaneous erasure of all physical backups.

Attachments are untrusted bytes; they are size/type limited, saved without parsing, and downloaded with attachment disposition and a non-executable content type. Links are never automatically fetched. Audio is saved without transcription or an implied interpretation. The person chooses what to type into an AI conversation. The current adapter never sends attachment bytes automatically.

The server permits guided internal edits under a scoped user permission. Revocation is checked at execution. Notifications are controlled by independent monitoring choices, quiet hours, daily budgets and pause settings. External sends, purchases, computer actions and shell operations have no executable tool. A text instruction in a message/file cannot change that policy. AI mutation proposals require a concrete user review and pass the same schema/evidence/version checks as a manual edit.

No-AI free text is captured verbatim except for a small, labeled guided-command vocabulary. Relative/ambiguous dates remain notes, not confirmed deadlines. The app is a support tool, not a clinician, diagnostic system, live tracker or emergency monitor. Explicit immediate-danger text prompts human-help resources; ordinary frustration is not classified as a crisis.

Browser notifications are implemented through the [Notifications API](https://developer.mozilla.org/en-US/docs/Web/API/Notifications_API) and require permission and a secure context (loopback is generally treated as trustworthy). Closed-browser delivery would require the [Push API](https://developer.mozilla.org/en-US/docs/Web/API/Push_API), a service-worker push subscription, a real push service/server, and platform-specific eligibility; no such service is configured. On supported iOS/iPadOS versions, web push requires a Home Screen web app and a permission request from a user gesture. Beside does not claim that capability. The app's supported delivery is its persisted inbox and notifications while an open page polls it.
